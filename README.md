# Machine Learning Algorithms Laboratory (ICS1512)

Machine Learning laboratory assignments completed as part of the **M.Tech Integrated Computer Science & Engineering** curriculum at **Sri Sivasubramaniya Nadar College of Engineering**.

## Repository Structure

```
ml_laboratory/
│
├── assign1/      # Python Libraries and Exploratory Data Analysis
├── assign2/      # Naive Bayes & K-Nearest Neighbors
├── assign3/      # Linear Regression Models
├── assign4/      # Logistic Regression & Support Vector Machine
├── datasets/     # Dataset files
├── images/       # Figures used in reports
└── README.md
```

## Experiments

| Experiment | Topic | Algorithms |
|------------|-------|------------|
